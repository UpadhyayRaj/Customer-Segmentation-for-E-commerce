# Customer Segmentation for E-commerce

## Project Overview

This project analyzes customer purchasing behavior using Exploratory Data Analysis (EDA), SQL, and Machine Learning techniques to identify meaningful customer segments. The objective is to help businesses understand customer behavior and create targeted marketing strategies.

---

## Objectives

- Perform Exploratory Data Analysis (EDA)
- Analyze customer data using SQL
- Apply K-Means Clustering
- Apply DBSCAN Clustering
- Reduce dimensions using PCA
- Visualize customer segments
- Generate business recommendations
